# MWA project instructions for Codex and Copilot

Read [MWA Web Project - Codex and Copilot Handover.md](<Project Documentation/2. Tech Docs/MWA Web Project - Codex and Copilot Handover.md>) before starting project work. This is the authoritative shared handover.

After every code, configuration, rule, deployment, integration or documentation change, update that handover before the final response, including partial/blocked work. Maintain current state, affected files, decisions, actual verification, Git/deployment status and next steps. Never claim an unverified deployment succeeded. Record documentation-only work too. Keep credentials and personal data out. Include the handover in the same commit as related work when committing is authorised; do not create a duplicate per assistant. Honour user scope and existing approval requirements; this instruction does not itself authorise deployments, payments or messages.

Use the canonical repository, not the archived website or scratch workspace. Keep shared permission catalogs, rules and frontend guards consistent. For Admin Team changes run the owner/read-only render checks; builds alone missed a previous runtime crash. See the handover for commands and details.
